# Mi Panel Tecnológico

Mi primera página web: un espacio para presentar las tecnologías que estoy aprendiendo y mis proyectos. Está creada con HTML, CSS y JavaScript, sin frameworks ni dependencias obligatorias, y es compatible con GitHub Pages.

## Cómo abrirla

Abre el archivo `index.html` directamente en tu navegador. No hace falta instalar nada ni ejecutar un servidor.

## Publicar en GitHub Pages

Sube los archivos del proyecto a un repositorio de GitHub y, en **Settings → Pages**, elige la rama y la carpeta donde está `index.html`. GitHub Pages servirá la página de forma estática.
